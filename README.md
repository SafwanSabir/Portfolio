# Windows 95 Portfolio

A retro-style portfolio website built with React, inspired by the classic Windows 95 operating system. 

## Live Demo
https://SafwanSabir.github.io/Portfolio/

## Features
- Fully functional draggable and resizable windows
- Start Menu & Taskbar
- Customizable background and themes
- Integrated App Store
- Built-in games and utilities (Minesweeper, Paint, Note, Calculator)
- Fully responsive (Mobile & Desktop support)

## Technology Stack
- React
- Vite
- Framer Motion
- CSS3
